## 🚀 Giới thiệu

**Super MD** không chỉ là một trình soạn thảo Markdown. Đây là một không gian sáng tạo được thiết kế để mang lại trải nghiệm viết lách mượt mà, trực quan và đầy cảm hứng. Với giao diện người dùng theo phong cách **Fluent 2**, Super MD kết hợp sự tối giản với các hiệu ứng animation tinh tế, giúp bạn tập trung vào nội dung mà không bị phân tâm.

Dự án này được xây dựng với niềm tin rằng các công cụ chúng ta sử dụng hàng ngày nên đẹp đẽ, mạnh mẽ và thú vị.

## 🌟 Tính năng nổi bật

*   **🎨 Giao diện Fluent 2:** Mọi thành phần, từ icon đến bố cục, đều được thiết kế theo nguyên tắc của Fluent 2, mang lại cảm giác quen thuộc và hiện đại.
*   **✨ Hiệu ứng Animation tinh tế:** Các hiệu ứng chuyển động (motion) được tích hợp một cách có chủ đích, tạo ra phản hồi tức thì và làm cho trải nghiệm người dùng trở nên sống động.
*   **✍️ Soạn thảo không giới hạn:** Chế độ xem trước trực tiếp (live-preview), chế độ tập trung (focus mode), và nhiều tính năng hỗ trợ viết lách hiệu quả.
*   **🧩 Khả năng mở rộng:** Dễ dàng tùy chỉnh và mở rộng với các plugin và theme.
*   **💻 Đa nền tảng:** (Dự kiến) Hoạt động trên Web, Windows, macOS và Linux.

## 🛠️ Công nghệ sử dụng

*   **Frontend:** React / Next.js
*   **UI Kit:** Fluent UI Web Components
*   **Styling:** CSS Modules / Styled Components
*   **Animation:** Framer Motion
*   **State Management:** Zustand / Redux Toolkit

## 📦 Cài đặt và sử dụng

Hướng dẫn chi tiết sẽ sớm được cập nhật khi phiên bản đầu tiên được phát hành.

```bash
# Clone a repo
git clone https://github.com/your-username/super-md.git

# Go to the project directory
cd super-md

# Install dependencies
npm install

# Start the development server
npm run dev
```
